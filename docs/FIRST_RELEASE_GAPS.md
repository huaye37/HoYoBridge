## 当前实际状态

- 原神保留原有产品下载器；另三款已接入 OfficialGameInstaller 原生按钮与后台官方下载引擎。自动获取/校验/解包引擎、独立选目录、进度、暂停及冷启动续传已实测。崩坏3完整下载结束并独立校验1,056文件、34,815,890,010字节，零失败。星铁、绝区零新适配器的完整下载仍未复测，不把通用接入当作逐游戏验收。
- 官方 getGameBranches 当前星铁 4.5.0、绝区零 3.1.0、崩坏3 9.0.0。getGamePackages 却返回星铁 4.4.0、绝区零 3.1.0、崩坏3 8.4.0，原神包更停在 5.5.0。不能将旧接口的整包直接当作当前版本一键安装。
- 运行时准备已有包内来源，但无 Rosetta 缺失的完整引导。没有干净 Mac 端到端验收。
- 当前只有 Apple Development 证书，没有 Developer ID Application 分发证书。开发包 ad-hoc 签名不是公证。
- git remote 为空；2026-09-08 检查 huaye37 仓库列表未找到本启动器，GenshinMeta 是独立的伤害计算网页。尚未确认本项目的发布仓库，因此自身更新源及发布目标无法确定。
