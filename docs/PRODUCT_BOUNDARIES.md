# 产品与风险边界

## 产品定义

MacGameBridge 的目标不是承诺所有未来版本永远可运行，而是建立一套能够快速发现变化、隔离故障、更新兼容配置、回滚失败修改并给出明确诊断的维护系统。

## 首期范围

- 《原神》国服。
- Apple Silicon Mac。
- macOS 26 和 macOS 27。
- 游戏下载、续传、更新、完整性校验和修复。
- Wine、DXMT、GPTK/D3DMetal 运行时管理。
- 标准模式与实验兼容模式。
- 本地诊断、脱敏日志、兼容性报告和性能基准。

国际服、Intel Mac、其他游戏和 App Store 发布不属于首期范围。

## 标准模式

- 只启用经过当前游戏版本验证的运行时与启动配置。
- 不修改游戏核心文件，不修改系统网络配置。
- 下载和更新必须校验并支持回滚。
- 即使处于标准模式，也明确提示 macOS 不是游戏官方支持平台。

## 实验兼容模式

实验兼容模式不是一个无条件放行开关。开启模式后，每项中高风险操作仍需展示：

- 修改目标和具体差异。
- 来源、版本和哈希。
- 账号、稳定性和系统影响。
- 自动恢复方式和手动恢复步骤。
- 真实验证状态。

实验模式可以研究未验证的 Wine、DXMT、D3DMetal、启动参数和可恢复兼容补丁，但不集成作弊、服务器数据修改或影响联机公平性的能力。

打开实验模式只代表允许查看候选项，不会自动选择实验配置。真正启动前必须明确选择具体配置，并确认与当前目录 revision、原始 payload SHA-256、配置 revision 和风险声明摘要绑定的声明；配置、签名 payload 或声明变化后需要重新确认。实验模式也不能绕过下载哈希、目录签名和来源校验。

## 无法承诺解决的情况

- 游戏厂商要求只有真实 Windows 内核才能工作的反作弊机制。
- 厂商主动阻断非官方平台或处罚账号。
- 服务端停机、账号异常和区域网络限制。
- macOS 移除必要的系统能力，例如 Rosetta。
- 尚未公开的新协议、新加密或资源格式。

这些情况应被识别并准确报告，不能伪装成已支持。
