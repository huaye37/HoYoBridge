# 星桥 HoYoBridge 0.1.16

发布日期：2026 年 11 月 16 日

## 改进与修复

- 修复部分 SMB 网络磁盘在文件复制、校验完成后，因不支持独占目录重命名而导致迁移失败的问题。
- 兼容处理先独占创建空目标目录，再切换已校验副本；不覆盖已有同名目录，也不删除原游戏。
- 最后一步目录切换失败时保留已校验副本，并记录恢复位置；通过「完成迁移关联」重试，不再丢弃整份副本重新复制。
- 补充迁移阶段诊断记录；恢复已登记的临时副本时重新校验，仅重复制不完整或校验不一致的文件。

## 升级方式

- 在「设置 → 应用更新 → 检查更新」确认安装 0.1.16，然后从游戏「… → 迁移游戏位置」自行开始迁移。
- 原游戏、账号和兼容环境不受此次启动器更新影响。迁移成功后原副本仍保留，确认新位置正常后再自行清理。
- Apple Silicon、macOS 26 及以上；轻量包采用 ad-hoc 签名，尚未完成 Apple 公证，更新目录及 ZIP 使用 Sparkle Ed25519 签名。

## 验证情况与已知问题

- 已在真实 SMB 挂载上复现旧调用返回「Operation not supported」，修正后的测试客户端复制、校验和目录切换通过。
- 覆盖八个客户端的复制校验、目标冲突保留、关联失败重试及保留副本复用测试。
- 大体积星铁迁移按用户要求中止并删除了临时副本，原游戏和启动路径保持不变；不将小文件测试描述为完整游戏迁移或迁移后游玩通过。
- 网络盘逐文件校验需读取副本，不能消除网络和磁盘本身的耗时。复制阶段强制退出的自动发现和恢复不在本次验证范围内。
