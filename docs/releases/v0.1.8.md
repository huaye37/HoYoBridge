# 星桥 HoYoBridge 0.1.8 测试版

- 每款游戏标题旁增加「国服／国际服」选择，记住每款游戏上次使用的客户端，并显示已安装或下载未完成状态。
- 国服与国际服分别管理安装目录、下载任务、更新和运行环境。原有国服路径保持原位，新国际服默认使用带 `Global` 后缀的独立目录，禁止目录重叠。崩坏 3 此轮国际服明确为欧美客户端。
- 未完成的首次下载新增「… → 取消下载并清理文件…」。确认后停止对应下载服务并清理当前客户端；已安装游戏、另一客户端、更新和修复任务不进入此入口。官方服务删除的文件无法恢复，残留文件可用时移到废纸篓。
- 已暂停任务可选择「结束任务，保留文件」，之后可以继续使用其他游戏或更新启动器。
- 主页显示当前客户端的「游戏占用」；首次下载中显示「已下载文件占用」。统计包含隐藏下载文件，不跟随链接进入其他客户端；下载中显示扫描快照，可从菜单重新统计。
- 保留四角色图标、中文更新窗口及共用的全屏／窗口、启动分辨率设置。每个客户端的游戏内设置独立。

验证：四款国际服的安装信息已通过独立的官方 HoYoPlay 后台读取；隔离的崩坏 3 国际服实际短下载、暂停、取消清理通过。目录分类、偏好持久化、清理拒绝条件和文件占用统计通过针对性测试。

全量 Swift 测试 461 项通过；常规窗口与最小窗口已完成离屏布局检查，测试窗口未显示到用户桌面。

国际服完整安装、实际启动、登录、手柄与性能尚未逐款验收。界面会标明国际服启动兼容性待实测，不能将本版的下载管理验证理解为四款国际服均已可玩。

未公证 Pre-release：应用为 ad-hoc 完整性签名，更新目录和 ZIP 使用 Sparkle Ed25519 签名。通过「设置 → 应用更新 → 检查更新」由用户确认安装。
