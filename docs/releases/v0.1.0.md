# 星桥 HoYoBridge v0.1.0 · 测试版

面向 Apple Silicon Mac 的非官方米哈游国服游戏启动器。

## 下载与打开

- 下载 `HoYoBridge-macOS-arm64.zip`，解压后将 `HoYoBridge.app` 放入「应用程序」。
- 需要 macOS 26 或更新版本；当前适配范围为 macOS 26/27，不支持 Intel Mac。
- **尚未完成 Apple 公证。** 首次打开可能提示无法验证开发者或无法检查恶意软件。确认下载来源可信后，在「系统设置 → 隐私与安全性」中选择「仍要打开」，按提示确认。由此带来的不便，敬请谅解。
- 完整性校验文件为 `HoYoBridge-macOS-arm64.zip.sha256`；SHA-256 不等于 Apple 公证。不要求全局关闭系统安全功能。

## 本版内容

- 原神、崩坏：星穹铁道、绝区零、崩坏 3 独立管理，**仅国服官服**，不支持国际服和渠道服。
- 后台官方下载引擎适配、目录选择与关联、更新检查、校验修复及卸载入口。
- 游戏独立封面、中文界面及固定 CrossOver Wine 11.0-1 / DXMT 0.80 兼容配置。
- 默认关闭的原神 120 FPS 实验选项和 Metal HUD。

## 已知限制

- 这是早期测试版，不保证所有设备或后续游戏更新均可用。各游戏的真实验证范围见 README，不能把其中一款的结果推定为四款全部通过。
- 自更新客户端已接入，但在线更新源和密钥尚未配置；本版需手动下载后续版本。
- 玩家反馈自动上传功能尚未开放，请通过 Issues 提供脱敏复现信息。
- NAS、完整迁移、干净 Mac 首次安装及真实新版本维护仍有未完成的验收项。
- 第三方组件、游戏角色及图片属于各自权利人；详细来源、许可及尚待核对的分发事项见 THIRD_PARTY_NOTICES.md，本项目 MIT 不覆盖第三方资源。

本机 441 项测试通过；下载、登录、持续运行与跨机器兼容性是不同阶段，自动化测试不是全部游戏端到端认证。本版未进行新的游戏下载或卸载测试。
