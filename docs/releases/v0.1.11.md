# 星桥 HoYoBridge 0.1.11 测试版

- 其他游戏下载、更新或修复时，已安装且没有自身维护任务的游戏可以启动。
- 启动限制按具体客户端判断：国服与国际服分别处理；当前客户端的未完成下载、修复或卸载仍需先完成。
- 页面提示说明后台任务不妨碍启动当前游戏；仍只跟踪一款运行中的游戏，启动器自身更新继续等待游戏和下载任务结束。

验证：覆盖八个客户端的下载／更新／修复、已结束但未完成任务、卸载状态及跨客户端启动限制，release 构建与签名检查。真实游玩时的下载速度和帧率仍受网络与磁盘负载影响，本版未新增游戏性能实测结论。

未公证 Pre-release；应用采用 ad-hoc 完整性签名，更新目录及 ZIP 使用 Sparkle Ed25519 签名。在设置中由用户确认安装。
