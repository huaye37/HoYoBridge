# 星桥 HoYoBridge 0.1.18

发布日期：2026 年 11 月 17 日

## 改进

- 绝区零国服／国际服主页、安装位置选择及迁移窗口增加存储建议：优先本机磁盘，不推荐网络盘游玩；外置 SSD 需要确认接口、线材和实际读写稳定。
- 更新绝区零国际服验证说明：用户已确认 3.3.0 迁到本机后可以正常打开，持续游玩仍待验证。
- README 同步记录本机正常启动与当前网络盘体验反馈，不把个别环境结果泛化为所有设备结论。

## 升级方式

- 在「设置 → 应用更新 → 检查更新」确认安装。此次仅更新提示，不移动游戏、不修改账号环境或运行参数。
- Apple Silicon、macOS 26 及以上；轻量包采用 ad-hoc 签名，尚未完成 Apple 公证，更新目录及 ZIP 使用 Sparkle Ed25519 签名。

## 验证情况与已知问题

- 已核对用户当前安装为 0.1.17、绝区零国际服为 3.3.0，路径位于本机磁盘；正常打开由用户确认。
- 文案与界面接入完成构建检查；没有将本轮说明更新写成新的启动修复或性能优化。
- 网络盘表现来自用户当前环境反馈，尚未完成存储吞吐、延迟和持续游玩的对照测量。
