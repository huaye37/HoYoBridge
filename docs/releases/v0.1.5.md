# 星桥 HoYoBridge 0.1.5 测试版

未公证的 Pre-release；应用使用 ad-hoc 完整性签名，更新目录和 ZIP 使用 Sparkle Ed25519 签名，不是 Apple Developer ID 签名或公证。其他 Mac 的默认 Gatekeeper 首次打开体验尚未验收。

- 已带更新入口的用户可在「设置 → 应用更新」检查、下载并确认安装，更新仅替换启动器，不迁移游戏和账号环境。
- 0.1.0 等尚无更新配置的旧版须手动安装本版一次，后续在设置更新。
- 游戏主页安装路径下显示网络盘／外接盘性能提示，不将所有外接盘误报为必然卡顿。
- 首次需要运行组件时直接从上游下载并逐项校验；已有兼容环境继续使用，不因启动器升级重新安装游戏。
- 测试包不捆绑待核对再分发义务的 Wine/DXMT/Steam/7zz 或官方封面。图标改为无角色门户，官方游戏背景继续按需在线加载，离线保留已缓存图片。

验证范围：Swift 测试、release 构建与嵌套签名校验；真实上游组件下载校验；隔离目录的 Wine、DXMT 与 prefix 准备。实际游戏下载、登录、性能和游戏内全屏悬停行为没有因上述检查而重新获得验收。
