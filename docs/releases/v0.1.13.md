# 星桥 HoYoBridge 0.1.13

发布日期：2026 年 11 月 16 日

## 新增功能

- 设置增加「游戏显示器」，分别显示 Mac 内建屏幕和外接显示器。通过稳定标识记住所选屏幕，断开后临时回退到可用横屏。
- 识别竖屏并标注为不用于游戏；自动选择、窗口首次定位和分辨率预设不再混入竖屏。

## 改进与修复

- 各游戏使用同一套目标显示器、启动窗口尺寸与 macOS 绿钮全屏入口；窗口首次居中到所选横屏，之后不持续覆盖用户拖动和缩放。
- 分辨率列表按目标屏幕枚举，同时保留常用 16:9、16:10、超宽屏尺寸和自定义输入。
- 修正 Retina / HiDPI 像素与窗口逻辑尺寸的换算，避免把 4K 屏的 5K 渲染缓冲误写成面板原生分辨率。
- 明确区分「下次启动时的尺寸」与「游戏内实时设置」，不再让启动器设置看起来像能即时修改运行中游戏。

## 升级方式

- 在「设置 → 应用更新」检查并确认安装，然后在「游戏」页选择内建屏幕或外接横屏。
- 更新仅替换启动器；游戏文件、账号环境和下载记录保留，无需重下游戏。
- 安装包 `HoYoBridge-macOS-arm64.zip` 适用于 Apple Silicon、macOS 26 及以上。尚未完成 Apple 公证，应用为 ad-hoc 签名，更新目录及 ZIP 使用 Sparkle Ed25519 签名。

## 验证情况与已知问题

- 本机已识别三屏：273B1C 横屏、Mac 内建屏幕、HX270S 竖屏。显示选择、断开回退、竖屏排除、各游戏参数传递及原生窗口尺寸换算均有自动化覆盖。
- 游戏内部的分辨率菜单仍由游戏及 Wine 枚举；此版不能承诺增加游戏内全部选项，原生全屏下窗口大小也不能等同于游戏渲染分辨率。三款游戏在两块横屏上的逐项实际游玩验收尚未完成。
- 绝区零国际服的偶发 `MHYPBase.dll` 启动崩溃仍在调查，此版不宣称修复该闪退。
