# 星桥 HoYoBridge 0.1.12 测试版

- 允许游戏运行或下载暂停时检查、下载启动器更新。确认安装后，已暂停的下载自动结束后台任务并保留文件和续传记录；游戏或下载仍在运行时等待，退出游戏并暂停下载后继续安装。
- 「运行环境」增加玩家确认可正常游玩的版本：原神国服 7.2.0、星穹铁道国服 4.7.0。其他游戏、国际服及后续版本独立验证，安装完成不自动等于可玩。
- 补齐 16:10、MacBook 原生尺寸、超宽屏及高分辨率常用选项，保留全部已枚举的显示器模式，增加自定义宽高。切换屏幕后刷新列表。
- 修复星铁保存的游戏全屏配置覆盖启动器窗口设置的问题。统一先进入普通可缩放窗口，原生绿钮控制 macOS 全屏；只应用窗口方式及启动尺寸，保留画质、语言和账号设置。
- 星铁国服改用专用启动辅助程序：首次安装或辅助程序更新时授权，之后复用，不保存管理员密码。使用固定且短暂的启动兼容操作，自动恢复系统记录。

验证：471 项 Swift 测试通过；真实隔离下载的暂停更新准备、文件和续传记录保留、后续清理通过；窗口控件、分辨率配置、专用辅助程序临时文件与用户级 launchd 通信／自动恢复测试通过。当前正在运行的游戏未被退出，首次系统级辅助程序安装及新窗口行为的实际游玩验收仍待用户使用新版完成。

本轮验证环境：Apple M5 Pro、macOS 27.3、固定 CrossOver Wine 11.0-1 + DXMT 0.80。玩家已确认可游玩版本为原神国服 7.2.0、星穹铁道国服 4.7.0；新的窗口及辅助程序行为仍单独验收。

游戏内分辨率菜单由游戏自身枚举；启动器提供全部显示器模式和自定义尺寸，不承诺能改变游戏内部的全部菜单选项。

未公证 Pre-release；应用使用 ad-hoc 完整性签名，更新目录及 ZIP 使用 Sparkle Ed25519 签名。更新由用户在设置中确认。
