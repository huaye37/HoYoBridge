# 星铁国服一次授权启动辅助程序

0.1.12 起，星铁国服启动使用专用 launchd 辅助程序，不再每次以管理员身份运行应用目录中的 Ruby 脚本。

- 首次启动由系统请求管理员授权，将随包自有程序安装至 `/Library/PrivilegedHelperTools/cn.yeutech.HoYoBridge.StartupHelper`，配置保存在 `/Library/LaunchDaemons/cn.yeutech.HoYoBridge.StartupHelper.plist`。
- 后续启动检查安装文件的 root 所有权、不可由组／其他用户写入、程序 SHA-256 与注册用户 UID，再通过固定 Unix socket 发出固定 `START` 请求。程序内容或注册用户变化需要重新授权；不保存密码、不设置免密码 sudo。
- 辅助程序只接受注册 UID 的本机连接。不能从请求中指定命令、文件、主机名或持续时间。唯一功能是为 `globaldp-prod-cn01.bhsr.com` 添加带独立标记的 15 秒启动兼容记录，随后恢复；保留其他 hosts 内容和文件权限，拒绝符号链接和已有的管理员域名配置。
- 原子写入前核对原文件身份及修改时间；正常结束、TERM/INT 和下次服务启动会清理自有标记。它不提供通用管理员执行能力。
- 更新启动器不会修改辅助程序；只有下次启动星铁时才检查和按需安装。未启动星铁时没有新增管理员请求。

验证包括：临时文件添加／恢复、拒绝链接及已有配置；独立用户级 launchd 测试服务的 socket 激活、重复请求、TERM 与 15 秒恢复及拒绝非法消息。测试不安装系统级服务、不修改真实 `/etc/hosts`。首次系统授权安装及更新后的真实游戏窗口行为需在用户退出当前游戏并使用新版后验收。

卸载辅助程序时，先退出游戏，使用管理员权限停止对应 launchd 服务，确认自有 hosts 标记已经恢复，再删除上述两个 root 文件。不要删除其他 hosts 条目或其他应用的辅助程序。
