# 星桥 HoYoBridge

**让米哈游游戏在 Mac 上，拥有一个熟悉的入口。**

星桥是面向 Apple Silicon Mac 的非官方游戏启动器，围绕原神、崩坏：星穹铁道、绝区零和崩坏 3，提供独立安装、游戏管理和兼容环境准备。

选择想玩的游戏，确认安装位置，再从同一个界面启动。不必为了玩一款游戏，把另外三款也装进电脑。

[下载最新版本](https://github.com/huaye37/HoYoBridge/releases/latest) · [版本更新日志](https://github.com/huaye37/HoYoBridge/releases)

## 特点

- **按游戏独立安装：** 四款游戏分别管理目录与任务，不捆绑下载。
- **以游戏为主的界面：** 独立封面、明确的主操作按钮、任务进度和错误说明。
- **减少环境配置：** 启动器按需下载并准备固定兼容组件，不要求玩家安装 Docker、Python 或 Steam 客户端。
- **安装位置可控：** 提供本地推荐路径，也可选择其他目录或外置硬盘。
- **实验功能自选：** 120 FPS 目标与 Metal HUD 默认关闭。
- **启动器内更新：** 在「设置 → 应用更新」检查新版本、阅读中文更新日志，由你确认下载安装。可在游戏运行或下载暂停时检查、下载启动器更新；安装阶段等待游戏退出和下载暂停，保留游戏文件与续传记录。
- **国服／国际服分开管理：** 同一游戏的不同客户端分别保存目录、任务和运行环境，可同时安装。
- **下载与游玩互不占用入口：** 下载其他客户端时，可启动已经安装好的游戏；正在安装、更新或修复的客户端不能同时启动。
- **占用与清理：** 显示当前客户端的游戏／已下载文件大小；下错且未完成的首次下载可取消并清理。

星桥与米哈游、HoYoverse、Apple 或 CodeWeavers 无官方隶属或合作关系。

## 游戏支持情况

“曾经进入游戏”与“当前安装、更新、恢复流程全部验收”是不同状态。

| 游戏（国服） | 安装方式 | 当前验证范围 |
| --- | --- | --- |
| 原神 | 后台官方引擎适配器 | 用户已确认国服 7.2.0 可正常游玩；全新安装与后续版本更新仍分别验收 |
| 崩坏：星穹铁道 | 后台官方引擎适配器 | 用户已确认国服 4.7.0 可正常游玩，并有 PS5 蓝牙手柄反馈；全新安装与后续版本更新仍分别验收 |
| 绝区零 | 后台官方引擎适配器 | 已有用户测试反馈；新适配器的完整安装与更新链路仍待单独验收 |
| 崩坏 3 | 后台官方引擎适配器 | 新适配器已完成完整下载、独立文件校验及暂停／重启续传测试；后续版本维护仍需验证 |

四款游戏统一接入后台官方引擎，提供检查更新、更新、校验修复、目录关联与卸载入口。崩坏 3 已通过真实卸载测试，其他游戏尚未逐款卸载验收。窗口、手柄和性能表现不能在四款游戏间相互推定。

上述可游玩版本由用户于 2026 年 11 月 15 日确认；本轮环境为 Apple M5 Pro、macOS 27.3、CrossOver Wine 11.0-1 + DXMT 0.80。国际服已接入官方下载信息与独立管理，尚不列为已验证可玩；崩坏 3 国际服目前指欧美客户端。

每款游戏标题旁可选择「国服／国际服」，分别保存目录、下载进度、更新状态和运行环境。已有国服路径保持原位，新国际服默认使用带 `Global` 后缀的独立目录；不能把两套客户端关联到同一个或相互包含的目录。全屏／窗口与启动分辨率仍为启动器共用设置，游戏内画质、语言和登录状态由各客户端独立保存。

主页显示当前客户端的游戏占用，首次下载未完成时显示已下载文件占用；下载中数值为扫描时快照，可从菜单重新统计。未完成的首次下载可在「… → 取消下载并清理文件」中确认清理，更新／修复任务不会进入这个入口。官方服务删除的下载文件无法恢复，遗留文件可移入废纸篓时会保留恢复机会；清空废纸篓后才能释放对应空间。

## 系统要求

- **芯片：** Apple Silicon，当前不面向 Intel Mac。
- **系统：** 应用要求 macOS 26 或更新版本，项目适配范围为 macOS 26/27；测试版系统可能出现额外兼容问题。
- **Rosetta：** 兼容环境运行所需；应用会检查，缺失时提供安装指引。
- **空间：** 按所选游戏资源大小预检，另外需要运行环境、下载缓存和更新临时空间，不能只预留游戏最终占用。
- **网络：** 首次安装和更新需要访问官方资源服务。

当前固定组合为 **CrossOver Wine 11.0-1 + DXMT 0.80 + Steam 兼容组件**。兼容组件不是 Steam 客户端，不要求 Steam 账号。目前不支持任意替换 Wine；GPTK 不在产品提供的运行路线中。

## 安装与使用

### 获取应用

前往 [最新 Release](https://github.com/huaye37/HoYoBridge/releases/latest)，在页面底部 **Assets** 下载 `HoYoBridge-macOS-arm64.zip`，解压后将 `HoYoBridge.app` 拖入「应用程序」。普通用户无需克隆源码或自行编译。

每个新版本都直接发布到 **GitHub Releases**，提供安装包、SHA-256 校验文件和中文版本日志，不再标记 Pre-release。发布日志列出新增功能、改进与修复、升级方式及已知问题；历史版本保留在 [全部 Releases](https://github.com/huaye37/HoYoBridge/releases)。Release 分类不改变签名状态：当前应用仍未完成 Apple 公证。

附件文件名如下（`Source code` 是源码，不是应用安装包）：

```text
HoYoBridge-macOS-arm64.zip
HoYoBridge-macOS-arm64.zip.sha256
```

取得可信发行包后，在两个文件所在目录检查下载完整性：

```bash
shasum -a 256 -c HoYoBridge-macOS-arm64.zip.sha256
```

当前应用使用 ad-hoc 完整性签名，尚未完成 Apple 公证。首次打开被系统拦截时，确认来源与文件完整性后，按「系统设置 → 隐私与安全性」提示打开；无需全局关闭系统安全功能。

### 更新启动器

打开「设置 → 应用更新 → 检查更新」，阅读中文日志后确认安装。更新只替换启动器，不重新安装游戏，也不迁移游戏目录或账号环境。自动检查可自行开启，安装仍由你确认。

0.1.12 起，游戏运行时也能检查和下载启动器更新；安装时等待游戏退出及下载暂停，已暂停任务会保留文件和续传记录。仅 v0.1.0 等尚未内置更新源的早期版本需要手动安装一次新版，之后即可在启动器内更新。

### 安装游戏

1. 打开星桥，选择想玩的游戏。
2. 点击安装，确认推荐位置或选择其他磁盘。
3. 等待资源下载、校验和兼容环境准备完成。
4. 点击启动，在游戏内使用自己的账号登录。

四款游戏均提供“使用推荐位置”和“更改位置”选项。下载由后台官方引擎执行，不提供 YAAGL 下载入口或失败回退，应用包不再附带旧 YAAGL/Python 下载器。官方引擎窗口和 Dock 入口由后台模式隐藏；干净机器的完整无感流程仍在验证。

### 推荐安装目录

`~` 表示当前用户的个人文件夹，例如 `/Users/你的用户名`。

```text
~/Games/HoYoBridge/
├── Genshin Impact/
├── StarRail/
├── ZenlessZoneZero/
└── HonkaiImpact3/
```

只下载玩家选择的游戏。兼容环境和应用设置另存于本机应用支持目录。

- 已有安装路径不变，不因项目改名自动搬动文件。
- 外置硬盘需在安装、更新和运行期间保持连接。
- NAS 暂不推荐作为默认位置；直接运行、更新和断连恢复需要分别验收。
- 通用迁移和缓存清理尚未完成。卸载位于游戏管理菜单，会确认实际目录并永久移除游戏安装内容，无法从废纸篓恢复；请先备份目录中的个人文件。兼容环境与其他游戏保留。

## 窗口、分辨率与运行环境

启动器的窗口模式与启动分辨率应用于四款游戏；画质、语言等游戏内设置由各游戏独立管理。实际显示效果取决于游戏及兼容配置。

0.1.12 增加显示器模式、16:10／超宽屏／MacBook 常用尺寸与自定义分辨率。启动先进入可缩放的普通窗口，左上角绿钮负责 macOS 全屏；星铁独立的已保存全屏记录也会按启动器显示设置处理。游戏内部的分辨率菜单仍由游戏自身枚举。

0.1.13 增加「游戏显示器」：内建屏幕与外接显示器分别列出，竖屏标注为不用于游戏，所选屏幕断开时临时回退到其他横屏。分辨率列表按目标屏幕整理，窗口首次居中到该屏；后续拖动与缩放不被重复覆盖。HiDPI 的「当前渲染像素」不等于面板物理分辨率。以上设置在下次启动生效，并非游戏内实时分辨率控制；各游戏自己的可选菜单仍可能不同。

绝区零国际服已发现偶发保护模块 `MHYPBase.dll` 初始化崩溃，正在调查；窗口改进不代表已修复该闪退，三款游戏的双横屏实际游玩验证仍待完成。

运行环境页列出玩家已确认可正常游玩的原神国服 7.2.0、星穹铁道国服 4.7.0（2026-11-15），不将安装成功视作可玩确认。星铁国服的专用辅助程序改为首次安装或自身升级时授权，后续复用；用途和回滚说明见 [启动辅助程序](docs/STARTUP_HELPER.md)。

新窗口行为和首次系统级辅助程序安装仍待新版实际游玩验收；自动化测试通过不代表所有游戏、显示器和系统组合均已实测。

实验功能需要手动开启：

- **120 FPS 目标：** 默认关闭；为四款游戏设置 DXMT 渲染上限，原神额外尝试解锁。其他游戏仍受自身帧率限制，120 是目标而非保证。
- **Metal HUD：** 显示图形运行指标，不会自动提高性能。

游戏更新可能改变资源格式和启动条件，不能保证每次更新后无需适配即可启动。出现异常应保留现有目录和日志，不建议首先删除游戏。

## 开发与构建

项目使用 SwiftPM，要求 Swift 6.2 工具链及相应 Xcode。应用运行要求与核心包的最低编译平台声明不同。

获取源码并验证：

```bash
git clone https://github.com/huaye37/HoYoBridge.git
cd HoYoBridge
env -u PROTOC_PATH swift build
env -u PROTOC_PATH swift test
```

`SwiftProtobufPlugin` 是固定代码生成入口，请保留 `env -u PROTOC_PATH`，不要替换为未固定的系统 `protoc`。[CI 参考配置](.github/ci-reference.yml) 暂未启用：当前发布凭证没有工作流写入权限。该配置仅构建与测试，不执行发行打包，也不证明游戏可玩。

准备好打包脚本要求的固定 `LocalRuntimes` 资产后：

```bash
# 开发构建并打开应用
bash script/build_and_run.sh

# 本地优化构建，生成测试 ZIP 和 SHA-256（不是 GitHub Release，不上传）
MGB_BUILD_CONFIGURATION=release bash script/build_and_run.sh --package

# 检查 ZIP 内应用的标识、架构、签名和下载完整性
bash script/verify_release.sh --local

# 正式分发前额外检查 Gatekeeper 与公证票据
bash script/verify_release.sh --public
```

产物为 `dist/HoYoBridge.app` 和 `dist/HoYoBridge-macOS-arm64.zip`。`--public` 不会自动签名或公证，当前 ad-hoc 包不满足正式分发验收。

命令中的 `release` 只是编译优化配置，不代表已上传。当前 GitHub CI 尚未启用，本机执行构建和测试。每个交付版本都发布为普通 GitHub Release，附安装包、SHA-256 和中文日志，并同步经过签名的启动器更新目录；未公证状态与实测范围如实写明。具体步骤见 [自更新发布说明](docs/LAUNCHER_SELF_UPDATE.md)。

功能变更时同步更新本 README 的功能、使用方式和限制；每版细节另外记录在 `docs/releases/v版本号.md`，用于 Release 正文和启动器更新弹窗。

**仅克隆源码不能重现完整发行包：** `LocalRuntimes` 不入库，组件获取来源和可再分发范围仍需完善。打包脚本会关闭正在运行的星桥启动器，不会借此结束游戏进程。

对外名称为「星桥 HoYoBridge」。为兼容已有安装，Swift 包名、可执行文件、内部标识和历史数据目录仍保留 `MacGameBridge`，请勿全局替换。

## 技术结构

- `Sources/BridgeStatus`：macOS 界面、四游戏状态、安装维护适配、兼容启动和启动器自更新。
- `Sources/BridgeCore`：资源清单、校验、存储、命令执行及底层能力；保留的清单研究代码不等于当前产品仍使用旧下载器。
- `script`：本机打包、验证及实验辅助脚本；部分脚本依赖未入库的固定本地资产。
- `Tests`：自动化测试；测试通过与游戏真实登录、游玩、版本更新验收分别记录。
- `LICENSES`、`THIRD_PARTY_NOTICES.md`：第三方许可原文及用途、来源说明。
